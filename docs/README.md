# Documentation Reviseo

Ce dossier contient toute la documentation technique et les changelogs du projet Reviseo.

## 📁 Structure

```
docs/
├── README.md              # Ce fichier
├── CHANGELOG.md           # Historique des versions et améliorations
└── changelog/             # Documentation détaillée des améliorations
    ├── BREVET_COMPLET_README.md
    ├── BOUTON_RETOUR_AMELIORE_README.md
    ├── PROGRESSION_AMELIOREE_README.md
    ├── SHUFFLE_OPTIONS_README.md
    ├── RANDOM_QUESTIONS_README.md
    └── HISTOIRE_GEO_README.md
```

## 🎯 Objectif

Cette organisation permet de :
- **Centraliser** toute la documentation technique
- **Organiser** les améliorations par version
- **Faciliter** la navigation et la recherche
- **Maintenir** une structure claire et professionnelle

## 📖 Comment Utiliser

### Pour les Développeurs
1. Consultez le [CHANGELOG.md](./CHANGELOG.md) pour voir l'historique des versions
2. Naviguez vers les fichiers détaillés dans `changelog/` pour plus d'informations
3. Utilisez cette structure pour documenter les futures améliorations

### Pour les Utilisateurs
- Le [README principal](../README.md) reste à la racine pour une vue d'ensemble
- Cette documentation est principalement technique et destinée aux développeurs

## 🔄 Workflow de Documentation

### Ajouter une Nouvelle Amélioration
1. Créer un fichier détaillé dans `changelog/`
2. Mettre à jour le [CHANGELOG.md](./CHANGELOG.md)
3. Ajouter une entrée dans la table des versions

### Format Recommandé
```markdown
# Titre de l'Amélioration

## 🎯 Problème Identifié
Description du problème résolu

## 🔧 Solution Implémentée
Détails techniques de la solution

## 📊 Impact
Mesures d'amélioration et métriques
```
